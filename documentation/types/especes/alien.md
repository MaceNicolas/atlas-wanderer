# Fiche d'espèce : les Aliens

Espèce **générique**, par défaut. Les éléments non arrêtés sont marqués **[à définir]**.

## 1. Vue d'ensemble

| | |
|---|---|
| **Nom** | Alien |
| **Type** | Peuple humanoïde |
| **Univers** | Atlas Wanderer |
| **Rôle dans le jeu** | Espèce par défaut : tout serviteur a une espèce, et l'Alien est celle qui ne ressort pas |
| **Silhouette** | Humanoïde ordinaire **[à définir]** |
| **Traits distinctifs** | Aucun voulu : c'est la référence des autres espèces |

## 2. Dans le jeu

- Chaque serviteur a **une espèce** et **un archétype obligatoire** (section 4 de `documentation/idees/nouvelles.md`). L'Alien évite que chaque carte doive inventer une espèce exotique.
- Thématique et mots-clés plus présents : aucun en particulier **[à définir]**. L'espèce reste neutre pour que l'archétype porte l'identité de combat.
- Archétypes associés : tous.

## 3. Éléments à définir

| Sujet | Questions |
|---|---|
| **Apparence** | Une silhouette ou plusieurs ? Quelle diversité visuelle ? |
| **Origine** | Planète d'origine, rapport à l'espace et aux autres peuples. |
| **Place dans l'équipage** | Majorité de l'équipage ou un peuple parmi d'autres ? |
| **Particularité** | Une petite caractéristique mécanique, ou aucune volontairement ? |
