# Documentation d'Atlas Wanderer

Point d'entrée de la documentation du jeu. Le texte de référence actuel reste `NEW_IDEAS.md` à la racine du dépôt.

## Sommaire

- [`types/`](types/types.md) : les types de serviteurs et de héros.
  - [`types/archetypes.md`](types/archetypes.md) : les spécialités d'équipage.
  - [`types/especes/`](types/especes/especes.md) : les espèces (Alien, Elk, Dwork, Droïde, Sorvane).
- [`mecaniques/`](mecaniques/mecaniques.md) : les règles du jeu (à venir, aujourd'hui dans `NEW_IDEAS.md`).

## Hors documentation

- `inspiration/` : images et matériau brut.
- `NEW_IDEAS.md`, `OLD_IDEAS.md` : idées et règles en cours.
- `prototype/` : prototype jouable. Ouvrir `index.html` à la racine (présentation, règles et serviteurs, lien vers le prototype), ou directement `prototype/prototype.html` (connexion nécessaire pour les styles). `apercu.html` (à la racine) montre les graphismes SVG.
